## Lektion

Die kritischsten Fehler entstehen beim Übersetzen von Fachkonzepten in Sprache —
nicht im Code selbst. Ebene 1 erfordert den originalen Prompt.

Was Ebene 1 nicht kann: Sie prüft ob die Formel vom Prompt abgedeckt ist —
nicht ob die Formel physikalisch stimmt. Dafür ist [[../ebene4-tests/index|Ebene 4]] zuständig.
